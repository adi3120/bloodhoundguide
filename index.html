03 / Find Domain Admins

Explore → Cypher → Saved Queries → search “Domain Admins”

Select the membership query. The current documented UI can auto-run selected queries; otherwise use its run/search control. For an explicit search scoped to the course domain, paste this in the Cypher editor:

MATCH p=(u:User)-[:MemberOf*1..]->(g:Group)
WHERE g.name = 'DOMAIN ADMINS@CORP.COM'
RETURN p

This follows direct and nested MemberOf relationships from users to the named group. Replace the group name if your lab uses another domain.

The lesson shows Administrator and Jeffadmin. Your graph must establish its own membership results; do not assume those accounts will always appear.

04 / Find a shortest path

Course-wide view

All starting points → Domain Admins

In Saved Queries, search Domain Admins and choose the shortest-path query. Read its description and Cypher to confirm its scope. A Tier Zero query can target more than Domain Admins.

Focused view

Stephanie → Domain Admins

Open Explore → Pathfinding. Select STEPHANIE@CORP.COM as the start and DOMAIN ADMINS@CORP.COM as the destination, using the suggestions.

Keep the relevant relationship filters enabled. The focused view answers whether your collected graph contains a route from Stephanie to the group; it does not enumerate every starting point in the domain.

A graph path describes potential access relationships. It does not demonstrate that an attack succeeded, that a session is still active, or that credentials can actually be recovered.

05 / Reproduce the “owned principals” workflow

  1. In Explore → Search, select STEPHANIE@CORP.COM.
  2. Right-click the node and choose Add to Owned.
  3. Wait for any triggered analysis to finish, then open Explore → Cypher → Saved Queries.
  4. Search for owned. Choose the appropriate path query and confirm whether its destination is Domain Admins, Tier Zero, or another set.

If a matching prebuilt query is unavailable, use the focused Pathfinding search from Stephanie to Domain Admins. That reproduces the single-user investigation without relying on a particular owned-tag query format.

Keep the annotation accurate. Owning Stephanie’s credentials does not mean owning CLIENT75 as a computer identity or administrator. The lesson uses CLIENT75 as a simplifying assumption. Mark it owned only for an explicitly hypothetical exercise or when your actual control justifies that label.

Use CE’s UI to manage Owned status. Legacy queries using owned:true are not automatically compatible with CE’s tagging model.

06 / Read the nodes and edges

Click a node to open its Entity panel. Expand Members, Member Of, Sessions, or Local Admin Privileges where available. Click a line to inspect the relationship.

RelationshipInterpretation
MemberOfA principal belongs to a group. Nested group membership can extend the chain.
AdminToThe graph records local administrator rights over a computer. This is different from permission to use RDP.
CanRDPRDP access is represented. It does not, by itself, establish local administrator rights.
HasSessionCollection recorded a user session on a computer. Treat it as time-sensitive evidence, not proof of recoverable credentials.

The lesson’s example links Stephanie, CLIENT74, Jeffadmin, and Domain Admins. Inspect each edge in your own graph instead of assuming your ZIP contains the same chain.

07 / When the lesson and your screen disagree

I uploaded the ZIP, but search finds nothing

Check upload completion and any parsing errors. Confirm the ZIP contains SharpHound data and that its format is supported by your CE build. An older course collector may require replacement with a CE-compatible SharpHound collector. Recollection should stay within your lab scope.

Objects exist, but no path is returned

Check the selected domain, endpoints, direction, and edge filters. Confirm the necessary memberships, local-admin relationships, and session data were collected. “No path” means none was found in the available graph with those filters.

The owned-principal query returns nothing

Confirm that you used Add to Owned, allow analysis to complete, and inspect the saved query’s tag and target conditions. Try the explicit Stephanie-to-Domain-Admins Pathfinding search to separate a tagging issue from missing relationships.

I cannot find the exact prebuilt query

Expand Saved Queries and clear restrictive platform/category/source filters. Search a shorter term such as “admin” or “owned”. Additional queries are available in the official query library; use its CE import workflow if needed.

The graph is too small to read

Increase browser zoom with Ctrl + Plus, collapse unused side panels, and use graph zoom/fit controls. Click a node for its full label. Browser zoom and graph zoom affect different parts of the display.
